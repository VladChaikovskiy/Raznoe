# Katana Ctl

Android-приложение для управления комбоусилителем **BOSS Katana** по
**USB-кабелю** — открытый аналог официальных Katana Librarian / BOSS Tone Studio.
Подключаешь телефон к комбику кабелем USB-C, управляешь усилителем, эффектами,
каналами, сохраняешь пресеты.

> Интерфейс — русский. Ядро (протокол/USB) — Kotlin, покрыто автотестами.

---

## ⚠️ Честный статус (прочитай обязательно)

Протокол Katana не публичный — он расшифрован сообществом. Реализовано на основе
открытых проектов (snhirsch/katana-midi-bridge, katana-dev) и исследования
форумов/официальных материалов.

1. **Framing и контрольная сумма** (`F0 41 00 00 00 00 33 …`, команды `11`/`12`,
   Roland checksum) — **подтверждены и покрыты тестами** (сборка кадров, парсинг,
   2-байтовые параметры, упаковка USB-MIDI, Identity — 22 теста проходят).
2. **Карта адресов = профиль Katana MkII (model 0x33).** Это самый полный
   публично известный набор адресов. **Точные адреса Gen 3 сообществом ещё
   дореверсиваются** и в открытом виде отсутствуют. Поэтому:
   - приложение шлёт **Identity Request** при подключении и показывает ответ
     (по нему поймём model ID твоего Gen 3);
   - архитектура сделана как **сменный профиль** (model ID + таблица адресов в
     одном файле [`KatanaParams.kt`](app/src/main/java/com/raznoe/katana/protocol/KatanaParams.kt));
   - параметры, не подтверждённые для Gen 3, помечены **«(?)»**;
   - вкладка **«Консоль»** даёт инструмент, чтобы найти реальные адреса Gen 3.
3. **На реальном железе не тестировалось** (у сборщика нет ни комбика, ни
   телефона). Первый запуск с усилителем — за тобой; дорабатываем по логам.
4. **iOS не поддерживается** — по кабелю к Katana там подключиться нельзя без
   MFi. Официальное приложение Gen 3 на телефоне работает по Bluetooth (адаптер
   BT-DUAL), а не по кабелю; по кабелю реально только на Android.

## Как получить APK

Сборка идёт в **GitHub Actions**:
1. Открой вкладку **Actions** в репозитории → workflow **«Build APK»**.
2. В последнем успешном запуске внизу — **Artifacts → `katana-ctl-debug-apk`** (zip).
3. Распакуй → `app-debug.apk` → установи на телефон (разреши установку из
   неизвестных источников). Zip можно распаковать на ПК и перекинуть APK.

## Как подключить к комбику

1. **Включай Katana, удерживая кнопку [BOOSTER]** — так активируется режим
   **USB-MIDI** (без этого USB отдаёт только звук, без управления).
2. Соедини **USB-C телефона → USB-порт комбика** (при необходимости — переходник OTG).
3. Открой приложение → оно найдёт устройство Roland (VID 0582) и попросит
   разрешение на USB → **OK**.
4. Вверху появится «● …» и строка **ID: …** (ответ Identity — пришли мне её).

При подключении приложение выполняет рукопожатие (Identity + announce ×2 →
включение режима редактора `7F 00 00 01`=01 → пауза 100 мс → чтение состояния),
как это делает официальное ПО.

## Что умеет (интерфейс)

Четыре вкладки, приближенные к официальному приложению:

- **Усилитель** — выбор канала (Panel/CH1–CH4), тип усилителя, Gain, Volume,
  Bass/Middle/Treble, Presence.
- **Эффекты** — 5 секций (Booster, Mod, FX, Delay, Reverb) + Noise Suppressor:
  вкл/выкл, выбор типа эффекта из полного списка, основные параметры
  (drive/tone/level у бустера; time/feedback/high-cut/level у delay;
  type/time/pre-delay/density/level и фильтры у reverb).
- **Библиотека** — сохранение/загрузка текущего тона в JSON на телефоне.
- **Консоль** — отправка сырого SysEx, чтение блоков и лог TX/RX (инструмент
  для уточнения адресов Gen 3).

## Снятие логов для адресов Gen 3 (метод diff)

1. Вкладка **«Консоль» → «Прочитать блок»**: адрес `60 00 00 30`, размер `16`.
2. Запиши строки **RX** из лога.
3. Покрути **физически** одну ручку на комбике (например, Gain).
4. Снова «Прочитать блок».
5. Пришли оба RX — по изменившемуся байту определю точный адрес, впишу в
   `KatanaParams.kt` и поставлю `verified = true`.

## Архитектура

```
app/src/main/java/com/raznoe/katana/
├── protocol/
│   ├── KatanaSysEx.kt   — framing, checksum, Identity/handshake, парсинг (ядро, тесты)
│   └── KatanaParams.kt  — ПРОФИЛЬ УСТРОЙСТВА: адреса + типы эффектов (правится здесь)
├── usb/
│   ├── UsbMidiPacketizer.kt — SysEx ↔ 4-байтовые USB-MIDI пакеты (CIN 0x4–0x7)
│   ├── UsbMidiConnection.kt — USB Host API: интерфейс, bulk in/out, фоновое чтение
│   └── KatanaController.kt   — очередь с пейсингом, handshake, setParam, каналы, чтение
├── model/               — пресеты (JSON)
├── KatanaViewModel.kt   — состояние, декодирование блоков в параметры
├── MainActivity.kt      — разрешение USB, авто-подключение по кабелю
└── ui/                  — Compose UI (4 вкладки) + тема
```

**Транспорт.** Katana несёт стандартные USB-MIDI 1.0 пакеты по bulk-эндпоинтам.
Приложение claim-ит интерфейс через USB Host API (фильтр по Roland VID `0x0582`,
PID любой — Gen1/MkII/Gen3 разные), упаковывает SysEx в USB-MIDI пакеты, читает
ответы в фоновом потоке. Отправка идёт через очередь с паузами (запись ~4 мс,
чтение ~30 мс), чтобы не флудить комбик и не блокировать UI.

## Источники протокола

- [snhirsch/katana-midi-bridge](https://github.com/snhirsch/katana-midi-bridge) (GPL-2.0) — спецификация SysEx, адреса, handshake.
- [katana-dev](https://github.com/katana-dev) (lib-katana GPL-3.0, docs) — карта типов усилителей и эффектов.
- [S-A-Martin/Katana-Solutions-USB-MIDI-Foot-Controller] — тайминги и последовательность рукопожатия.
- Ветка сообщества по реверс-инжинирингу **Katana Gen 3** на VGuitarForums.

Использованы только факты протокола (последовательности байт/адреса —
некопирайтные), не исходный код GPL-проектов. BOSS и Katana — торговые марки
Roland Corporation; проект с ними не связан, сделан для личного использования.
