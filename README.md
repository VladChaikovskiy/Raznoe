# Katana Ctl

Android-приложение для управления комбоусилителем **BOSS Katana (Gen 1/2/3)** по
**USB-кабелю** — аналог официальных Katana Librarian / BOSS Tone Studio, но
открытый и редактируемый. Подключаешь телефон к комбику кабелем USB-C → OTG,
крутишь gain / громкость / эквалайзер / эффекты, переключаешь каналы, сохраняешь
пресеты.

> **Язык интерфейса — русский.** Ядро (протокол, USB-транспорт) — обычный Kotlin.

---

## ⚠️ Что важно понимать (честно)

1. **Протокол Katana не публичный.** Он расшифрован сообществом. Все команды —
   это MIDI-SysEx поверх USB. Каркас сообщений (`F0 41 00 00 00 00 33 …`,
   команды `0x11`/`0x12`, контрольная сумма Roland) **одинаков для всех
   поколений** — это реализовано надёжно и проверяемо.
2. **Адреса параметров для Gen 3 ещё уточняются сообществом.** В приложении
   заложена карта адресов от Gen 2 как *предварительная* (помечены `(?)` в UI).
   Единственный полностью подтверждённый адрес — `Reverb type`. Остальные, если
   не совпадут на твоём Gen 3, правятся **в одном файле** —
   [`KatanaParams.kt`](app/src/main/java/com/raznoe/katana/protocol/KatanaParams.kt).
   Для поиска правильных адресов есть вкладка **«Консоль»** (см. ниже).
3. **Приложение не тестировалось на реальном железе** при разработке (не было
   ни комбика, ни телефона под рукой у сборщика). Каркас корректен, но первый
   запуск с усилителем — это то, что подтверждает работу. Дорабатываем по логам.
4. **iOS не поддерживается** — Apple не даёт подключаться к таким USB-устройствам
   без MFi-сертификации. Реальный путь по кабелю — только Android.

## Как получить APK (без Android Studio)

Сборка настроена в **GitHub Actions**:

1. Запушь ветку (или открой вкладку **Actions** в репозитории на GitHub).
2. Дождись workflow **«Build APK»** (зелёная галочка).
3. Внизу страницы запуска — раздел **Artifacts** → скачай `katana-ctl-debug-apk`.
4. Внутри zip — файл `app-debug.apk`. Скинь на телефон и установи
   (нужно разрешить «Установку из неизвестных источников»).

Хочешь — можно запустить сборку вручную: **Actions → Build APK → Run workflow**.

## Как собрать локально (по желанию)

```bash
gradle wrapper --gradle-version 8.7   # один раз, если нет ./gradlew
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Нужен JDK 17 и Android SDK (Android Studio ставит всё сам).

## Как пользоваться

1. Соедини телефон и Katana кабелем (USB-C телефона → USB-B «TO PC/AMP» на
   комбике; при необходимости переходник OTG).
2. Открой приложение. Оно само найдёт устройство Roland и попросит разрешение
   на USB — нажми «OK».
3. Вкладка **«Управление»**: каналы, gain, громкость, эквалайзер, эффекты.
4. Кнопка **«Прочитать состояние»** запрашивает у комбика текущие значения.

### Вкладка «Консоль» — сердце доработки под Gen 3

- **Отправить сырой SysEx** — вбиваешь hex-строку и шлёшь напрямую.
- **Прочитать блок** — запрашиваешь кусок памяти комбика (RQ1).
- **Лог TX/RX** — видишь всё, что уходит и приходит.

**Как найти адрес параметра Gen 3 (метод diff):**
1. «Прочитать блок» с адреса `60 00 00 00`, размер, скажем, `64`.
2. Запиши, что пришло (RX в логе).
3. Покрути **физически ручку** на комбике (например, Gain).
4. Снова «Прочитать блок».
5. Сравни — байт, который изменился, и есть адрес этого параметра.
6. Впиши адрес в `KatanaParams.kt`, поставь `verified = true`.

Скинь мне такие логи — и я обновлю карту адресов.

## Архитектура

```
app/src/main/java/com/raznoe/katana/
├── protocol/
│   ├── KatanaSysEx.kt     — сборка/разбор SysEx, контрольная сумма (ядро, стабильно)
│   └── KatanaParams.kt    — КАРТА АДРЕСОВ (правится здесь; Gen3 — уточняется)
├── usb/
│   ├── UsbMidiPacketizer.kt — упаковка SysEx в USB-MIDI 4-байтовые пакеты
│   ├── UsbMidiConnection.kt — USB Host API: поиск интерфейса, bulk in/out, чтение
│   └── KatanaController.kt   — операции: setParam, query, program change, raw
├── model/
│   ├── Patch.kt / PatchStore.kt — пресеты (JSON в памяти приложения)
├── KatanaViewModel.kt     — состояние UI, подключение, логика
├── MainActivity.kt        — разрешение USB, авто-подключение при вставке кабеля
└── ui/                    — Compose UI (3 вкладки) + тема
```

**Транспорт.** Katana несёт стандартные USB-MIDI 1.0 пакеты по bulk-эндпоинтам
(проблема «нужен драйвер» — только у Windows). Приложение claim-ит интерфейс
через Android USB Host API, поэтому не зависит от того, распознаёт ли Android
устройство как MIDI-класс. Фильтр — по Roland VID `0x0582` (PID любой, чтобы
ловить и Gen 3).
