# Видео из кода

Ролики для TikTok/Reels, которые полностью «нарисованы» кодом, как у
[@RyanSael](https://x.com/RyanSael). Нейросеть не генерирует видео напрямую: она пишет HTML-сцену,
которая рисует каждый кадр, затем Chromium снимает кадры, а ffmpeg собирает MP4.

```
scene.html  ──renderAt(t)──▶  Chromium (Playwright) ──PNG-кадры──▶  ffmpeg ──▶  ролик.mp4
audio.mjs   ──синтез звука──────────────────────────────────────────▲
```

## Ролики

| Папка | Тема | Формат |
|---|---|---|
| [`tv-explainer/`](tv-explainer/) | Как устроен современный телевизор (2D, тёмный неон) | 1080×1920, 30 fps, 54 с |
| [`tv-3d/`](tv-3d/) | То же в 3D: светлый стиль, камера облетает каждую деталь | 1080×1920, 30 fps, 56 с |
| [`tv-cutaway/`](tv-cutaway/) | В стиле технических иллюстраций в разрезе (как Animagraffs): рентген корпуса, вырезанный угол матрицы, выноски | 1080×1920, 30 fps, 56 с |

## Как пересобрать

Нужны Node 18+, ffmpeg и Playwright (`npm i -g playwright && npx playwright install chromium`).
Для 3D-роликов один раз выполните `npm install` в папке `videos/` (ставит three.js).

```bash
# полный рендер → videos/tv-explainer/tv-explainer.mp4
node videos/render.mjs videos/tv-explainer

# только несколько кадров-превью (секунды) → videos/tv-explainer/stills/
node videos/render.mjs videos/tv-explainer --stills 3,10,25
```

Живой предпросмотр: запустите любой статический сервер из `videos/` (например `npx serve videos`)
и откройте `.../tv-3d/scene.html`, анимация будет крутиться по кругу.

## Как устроена 3D-версия

- Модели собраны прямо в коде из примитивов three.js: скруглённые блоки, сферы, цилиндры.
- Камера летает по ключевым точкам (`CAM` в `scene.html`). У каждого ключа свой тип движения:
  `slow` для плавного дрейфа и `whip` для быстрого «рывка» с разгоном и торможением.
- Тексты и подписи рисуются отдельным 2D-слоем поверх 3D. Выноски привязаны к точкам
  модели и гаснут, пока камера делает рывок.
- В `audio.mjs` «вжухи» звука синхронизированы с рывками камеры (список `WHIPS`).

## Стиль «в разрезе» (`tv-cutaway/`)

Ориентир — [animagraffs.com](https://animagraffs.com/): одна детальная модель, которую вскрываем по шагам.

- Светло-серый студийный фон, мягкие тени, реалистичные материалы: металл, пластик, зелёные платы.
- Задняя крышка становится «рентгеновской»: полупрозрачная с контурными линиями.
- Угол матрицы вырезается плоскостями отсечения (`clippingPlanes`). Срез закрашен плоским
  цветом каждого слоя, а вырезанный кусок выезжает и раскладывается на слои.
- Выноски: точка на модели, ломаная линия и номер в кружке. Заголовочный блок прижат влево.

## Как сделать новый ролик

1. Скопируйте папку `tv-explainer/` под новым именем.
2. В `scene.html` задайте `window.VIDEO = {width, height, fps, duration}` и перепишите сцены.
   Главное правило: всё на экране вычисляется **только из времени `t`** (никаких
   `Date.now()` и `Math.random()`), тогда каждый кадр рендерится точно и без рывков.
3. `audio.mjs` (необязательно) экспортирует `generate(duration, sampleRate)` → `{left, right}`.
4. Запустите `render.mjs`.

## Безопасные зоны TikTok

Сверху около 200 px занимают вкладки, снизу около 420 px подпись и ник, справа около 140 px
кнопки. Важный текст держите в полосе y ≈ 220–1480.
