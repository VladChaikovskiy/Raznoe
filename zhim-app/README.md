# Жим — дневник тренировок (Android)

Приложение для тренировок по вторникам и четвергам: волна жима лёжа от
максимума, рабочие веса, отметки подходов, свои упражнения, циклы без
ограничения, экран «Итоги» с аналитикой, подсказки веса гантелей от жима
штанги, история и резервная копия данных.

Это WebView-обёртка: вся логика в `app/src/main/assets/index.html`,
данные хранятся на телефоне (localStorage).

## Сборка

APK собирает GitHub Actions (`.github/workflows/zhim-apk.yml`) при каждом
изменении в `zhim-app/`. Последняя сборка лежит в ветке как
`zhim-app/dist/zhim.apk`; ещё одна копия — во вкладке **Actions** → запуск
**Build Zhim APK** → **Artifacts** → `zhim-apk`.

Локально: `gradle -p zhim-app assembleDebug` (нужен Android SDK).

## Обновление приложения

APK подписан отладочным ключом, который на сервере сборки каждый раз новый.
Поэтому новую версию поверх старой Android может не поставить. Перед
обновлением: **Настройки → Резервная копия → Скопировать данные**, сохраните
текст, удалите старое приложение, установите новое и вставьте данные обратно.
