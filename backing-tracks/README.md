# Sharp Dressed Man (ZZ Top): минус без гитары

`Sharp_Dressed_Man_backing_track_C_126bpm.mp3`: барабаны, бас и клавишный пэд, сгенерированные скриптом
`make_sharp_dressed_man_backing.py`. Это не оригинальная запись, а синтезированная подложка по гармонии песни.

- Тональность: C, темп 126 BPM, ровные восьмые
- В начале 1 такт отсчёта хэтом (4 удара)

| Секция        | Такты | Аккорды (1 аккорд = 1 такт)  |
|---------------|-------|------------------------------|
| Барабаны      | 2     | —                            |
| Интро-рифф    | 8     | C                            |
| Куплет 1      | 8     | C                            |
| Припев 1      | 8     | Bb F C C · Bb F C C          |
| Рифф          | 4     | C                            |
| Куплет 2      | 8     | C                            |
| Припев 2      | 8     | Bb F C C · Bb F C C          |
| Соло          | 16    | C                            |
| Куплет 3      | 8     | C                            |
| Припев 3      | 8     | Bb F C C · Bb F C C          |
| Соло-аутро    | 16    | C                            |
| Финальный удар| 1     | C                            |

Перед каждой новой секцией звучит сбивка малого барабана, а в её начале — удар тарелки.
Если нужна другая форма, темп или тональность, поменяйте `BPM`, `FORM` или `CHORUS` в скрипте и запустите его заново.
